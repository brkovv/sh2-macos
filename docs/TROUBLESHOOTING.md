# Troubleshooting

- Unsupported EXE: provide the Enhanced Edition executable with the exact SHA-256
  in the main README. A similarly named Director's Cut EXE is not interchangeable.
- Missing SDK/Homebrew: finish the prerequisite installation and rerun the app.
- First build takes time: look in Application Support/SH2-brkovv/logs for the
  current generation or build log. Subsequent runs reuse local generated sources.
- Mouse: F8 toggles, move to turn James, left click action, right click ready
  weapon, hold middle button and move for the original search camera.
- A cinematic uses its scripted camera. Fixed-camera gameplay is retained.
- Music/input issues: report the scene, action, version, Mac model and OS plus
  relevant text logs. Do not attach game archives, generated C or whole data folders.
- 60 FPS is experimental; 30 FPS is available for comparison in the launcher.
- Russian text: import your existing translations folder or run Start-SH2.command
  --russian from Terminal. Choose the text language in the launcher and restart.

No system-wide protection changes or automatic uploads are part of this installer.
